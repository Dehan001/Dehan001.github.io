# Farhan Noor Dehan — Academic Portfolio

Source for [dehan001.github.io](https://dehan001.github.io/), built with Hugo Blox.

## Local development

1. Install Hugo Extended 0.135.0 or later.
2. Run `hugo server` from the repository root.
3. Open the local address printed by Hugo.

## Main content

- `content/authors/admin/_index.md` — biography, education, experience, skills, awards, and profile links
- `content/_index.md` — homepage sections
- `content/publication/` — publication pages
- `content/project/` — research project pages
- `config/_default/` — navigation, appearance, SEO, and site settings

The site deploys to GitHub Pages through `.github/workflows/publish.yaml`.
